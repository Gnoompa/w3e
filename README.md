Project goal - provide a simple yet flexible way to organize events using blockchain technology. Blockchain brings interoperability, resilence and high availability, meaning the platform could easily integrate and be integrated in a wast field of already existing blockchain solutions for a greater exposure.

Roadmap:
Stage 0 - MVP (we've already got a list of features for MVP)

Stage 1 (ETA 3 mnths):

1. Professional website redesign. Focusing on providing web2 similar experience but with web3 features to avoid user confusion.
2. Event searching/filtering. Filter by name/date/location/tags
3. Ticket reselling royalty feature. Return some configurable amount to the organizer on every ticket resell.
4. iOS/Android wallet integration. Tickets could be added to wallets on iOS/Android devices
5. Fiat ramp. A way for a user to pay for a ticket using fiat money and not crypto.
6. Meta transactions. A way for a user not to pay a commission on ticket purchase - organizer would pay the fee
7. ***TBD*** Protocol token deploy. Used for early adopters airdrop whitelisting and a way of payout to event organizers

Stage 2 (ETA 2 mnths):

1. Token utility integration:
    * token is used in event/organizer reputation system. Reputation System - math model deriving the popularity of an event, based on demand and protocol token held by the organizer
    * event participant payouts based on how popular the event is. Meaning a participant could earn money if participated in an event that will become popular
    * protocol DAO voting. People decide what features will be prioritized
    * a way to fund the investors/advisors/marketing/developers/hackatons

Stage 3 (ETA 2 mnths):

1. Optional KYC itegration. Used to prevent violation of "1 ticket per person" rule.
2. Optional abstract user accounts. For users without a wallet a wallet will be created automatically to avoid wallet creation process
3. Event POA NFT. Organizers could grant event participants unique NFTs and use them in a ticket pricing model, allowing for NFT holders to recieve a discount
4. Going chain agnostic
5. Protocol DAO
